# Phase 2: authentication UI for HireFlow

Build the **authentication frontend only** for the HireFlow job portal using **React.js and Tailwind CSS**.

Do not create any backend APIs, authentication logic, JWT, database integration, or server-side code. This phase is only for the frontend UI and user experience.

## Pages to build

### Login page

Include:

* email input
* password input
* show/hide password toggle
* remember me checkbox
* forgot password link
* login button
* login as candidate or recruiter option
* link to register page

### Register page

Include:

* full name
* email
* phone number
* password
* confirm password
* role selection (Candidate / Recruiter)
* terms and conditions checkbox
* create account button
* link to login page

## Candidate registration fields

* full name
* email
* phone number
* skills
* preferred location
* years of experience
* upload resume placeholder
* short profile summary

## Recruiter registration fields

* company name
* recruiter name
* company email
* phone number
* company website
* company location
* company size dropdown
* industry dropdown

## UI requirements

* split-screen authentication layout
* professional blue and white design
* responsive mobile and desktop layout
* modern input fields
* rounded buttons
* clean typography
* subtle hover effects
* proper spacing
* reusable form components
* form validation UI states
* loading button states
* success and error message placeholders

## Navigation behavior

* clicking Login opens the login page
* clicking Register opens the register page
* role selection should visually highlight the selected option
* navigation should work using React Router

## Create reusable components

* InputField
* PasswordField
* RoleSelector
* AuthLayout
* PrimaryButton

Keep the code clean, modular, and portfolio-quality. This should look like a modern SaaS authentication interface similar to LinkedIn or Wellfound.
