# Phase 3: candidate dashboard UI for HireFlow

Build the **Candidate Dashboard frontend only** for the HireFlow job portal using **React.js and Tailwind CSS**.

Do not create backend APIs, authentication logic, database integration, or server-side code. This phase is only for the frontend UI.

## Dashboard layout

Create a professional dashboard with:

* Left sidebar navigation
* Top navigation bar
* Main dashboard content area
* Responsive mobile layout

## Sidebar menu

Include:

* Dashboard
* Find Jobs
* Applied Jobs
* Saved Jobs
* Resume
* Profile
* Notifications
* Settings
* Logout

Use icons for each menu item.

## Top navigation

Include:

* Search jobs input
* Notification icon
* User profile avatar
* Candidate name
* Profile dropdown

## Dashboard overview cards

Create summary cards for:

* Jobs Applied
* Interview Invitations
* Saved Jobs
* Profile Completion

Display attractive statistics with icons.

## Recommended jobs section

Create professional job cards showing:

* Job title
* Company name
* Location
* Salary range
* Job type
* Experience level
* Apply button
* Save button

Create at least 8 realistic job cards.

## Recent applications section

Create a table showing:

* Company
* Job title
* Applied date
* Status
* Action

Include status badges such as:

* Applied
* Under Review
* Interview Scheduled
* Rejected
* Offer Received

## Profile completion widget

Create a progress card showing:

* Resume uploaded
* Skills added
* Education completed
* Experience completed
* Profile completion percentage

Add a progress bar and completion checklist.

## Resume section

Create a card showing:

* Current resume name
* Upload new resume button
* Download resume button
* Last updated date

## Saved jobs section

Display saved jobs in a compact card layout with remove and apply buttons.

## Activity timeline

Create a recent activity feed showing:

* Applied for Frontend Developer
* Resume updated
* Recruiter viewed profile
* Interview invitation received
* Job saved

## Design requirements

* Professional blue and white color palette
* Dashboard-style modern UI
* Fully responsive
* Rounded cards
* Soft shadows
* Hover effects
* Clean typography
* Consistent spacing
* Reusable components

Create reusable components for:

* DashboardCard
* JobCard
* StatusBadge
* Sidebar
* TopNavbar
* ActivityItem
* ResumeCard
* ProgressCard

Use React Router navigation where appropriate.

Keep the code modular, clean, and portfolio-quality so it looks like a real job portal dashboard.
