# Phase 1: HireFlow frontend setup

Build the **frontend only** for a modern job portal called **HireFlow** using **React.js and Tailwind CSS**.

Do not create any backend code, APIs, database, authentication logic, or dummy backend integration. This phase is only for the frontend foundation.

## Project setup

* Configure Tailwind CSS properly
* Organize the project with a clean folder structure
* Create reusable React components
* Use React Router for page navigation
* Keep the code modular and easy to extend

## Folder structure

src/

* components/
* pages/
* assets/
* App.jsx
* main.jsx

## Build these pages

1. Home (Landing Page)
2. Login Page (UI only)
3. Register Page (UI only)
4. Jobs Page (UI only)
